## 工作室界面

主界面保留模型与研究范围、对话、简短操作入口和输入区。资料与模型设置默认收起，所有屏宽都按需打开抽屉；去掉原有介绍段落、重复提示与常驻设置侧栏。操作卡在对应回答下方显示，不占用底部输入区，长操作列表和长回答都不会把发送按钮挤出屏幕。

最近项目可直接选择。项目、任务、实验和文献详情都新增“AI 协助”入口；进入前提交尚未保存的编辑，失败时保留原页面和草稿。入口携带准确资料范围与问题草稿，不会自行发送请求。

## 真实读取与操作

工作室和顶栏副驾驶使用同一份当前账号资料。项目范围包括目标、任务、子任务、里程碑、实验、关联文献和笔记；也可选择单个任务、实验、文献，或工作区摘要。上下文包含真实 ID，按结构精简至预算内，JSON 始终完整；资料已删除或不可用时不会扩大读取范围。

| 功能 | 可执行内容 |
| --- | --- |
| 项目 | 新建项目，修改名称、问题、目标、状态与起止日期 |
| 任务 | 新建单项或批量任务，修改标题、说明、状态、优先级、截止日期 |
| 阶段规划 | 添加项目里程碑、任务子任务 |
| 实验 | 新建实验，追加目的、假设、方法、结果、观察、结论或下一步 |
| 文献 | 收录提供的文献并关联项目，填写空白笔记或明确追加已有笔记 |

这些操作通过原有 repository、DataContext 与同步通道保存；服务器继续按当前会话校验账号归属。登录用户的副驾驶可直接使用管理员配置的平台模型，本地模式保留个人接口。

执行前可展开目标与修改明细。单项或整组采纳后有明确结果与“查看记录”入口；整组操作在同一事务中执行，任一写入失败全部回滚。失败项保留并可重试，已执行项禁用再次执行。正常刷新会保留执行状态，连续追加会读取最新记录，避免旧快照覆盖。

类型、字段、枚举、日期、文本长度、批量大小和目标归属均有校验；不凭模糊标题随意选择记录。已有实验正文只追加，已有文献笔记默认不覆盖。格式错误或未知操作有可见反馈，不会显示为保存成功。

## 对话保存

对话、草稿、资料范围和执行状态按账号保存在本机浏览器，可从“对话记录”恢复。切换模型或范围时另开讨论，旧对话保留。当前保留最近 12 段对话，每段至多保留最近 40 条消息；存储失败时有提示，并阻止直接切走未能保存的讨论。

研究记录沿用原来的服务器同步；本机聊天记录当前不提供跨设备同步。

## 使用示例

1. 在项目详情点击 **AI 协助**。
2. 输入“把下一阶段拆成三个任务，添加一个验收里程碑”。
3. 查看任务、日期、关联项目与里程碑明细，逐项或全部采纳。
4. 点击“查看记录”，或在项目与任务模块刷新确认保存结果。

实验与文献入口同样可以用来追加实验复盘、整理阅读笔记；只会使用所选范围中实际提供的资料。需要先在平台模型设置或个人接口设置中接入可用模型。

- `npm run build`：类型检查及构建通过。
- 全量单元与集成测试：43 个文件、288 项通过。
- AI 真实读写闭环：49 项断言通过，使用临时账号、临时 SQLite 和本地模拟模型；检查实际写入、服务器同步、刷新可见、重复点击、失败重试、整组回滚与账号隔离。
