# 各模块布局与交互重构 · 2026-10-25

本轮针对页面结构重复、信息层级模糊，以及手机上“页面没溢出、内容却读不清”的问题进行改版。保留既有数据模型、账号隔离和业务功能，按使用场景重新组织界面。

## 页面变化

| 页面 | 新布局与行为 |
| --- | --- |
| 工作台 | 优先处理区展示真实待办；统计合并为一条简洁索引；快速捕获移入今日任务，减少首屏重复容器。 |
| 科研项目 | 阶段导航直接筛选；双列项目档案展示研究问题、任务进度、下一里程碑或任务、实验数与截止日期。 |
| 项目详情 | 独立的项目头部与研究问题；目标、里程碑、任务和资料使用不同的信息层级，去除重复问题文本。 |
| 我的任务 | 宽屏使用范围侧栏与任务处理区；窄屏范围横排，任务标题与日期分行，避免标题和日期挤成省略号；保留列表、看板、日历和批量操作。 |
| 实验记录 | 月份边栏与记录时间线；状态筛选直接呈现；参数表保留内部横向滚动。新建过程中禁用按钮，防止重复点击。 |
| 实验编辑 | 正文合并为连续文档，新增页内目录和滚动高亮；预览目录只包含有内容的部分；手机目录固定在正文顶部。 |
| 文献库 | 分类、文献索引、阅读桌分工明确；阅读桌使用真实文献与现有笔记；切换筛选时退出旧条目，已输入笔记仍在卸载时保存。取消双击文字意外触发沉浸模式的隐藏手势，保留显式菜单。 |
| AI 工作室 | 以对话为主，常用研究入口改为轻量工具区；模型与资料放在侧面设置区；简化面向用户的文案。 |
| 设置 | 宽屏目录侧栏、手机横向目录；目录跟随滚动，并保留接近页底时用户点击的分区高亮。 |
| 账号与管理 | 账号身份区与安全表单形成清楚的分区；管理统计整合为一个信息条，减少重复白卡。 |

## 统一规则

- 保留淡蓝主色，以实色阅读面、细边框和留白区分层级。主操作按钮统一使用主题蓝，深色模式使用对应的浅蓝按钮及深色文字。
- 取消项目卡片和 AI 入口的悬浮位移；抽屉、菜单与滚动行为继续沿用稳定性修复。
- 触屏按钮已达到实际点击尺寸时，不再额外扩大伪元素命中区，避免覆盖相邻按钮。
- 折叠导航按实际侧栏宽度布局，图标和选中标记不再超出边界。
- 修正深色主题继承浅色面板变量的问题，包括顶栏与玻璃背景的底色。

浏览器验收使用独立临时浏览器和测试记录；账号验收使用临时数据库，没有借用用户科研记录。200% 验证通过 640×500 的 CSS 视口及 DPR 2 模拟重排，不等同于所有设备的系统缩放或触屏键盘测试。

复查中发现并解决了手机任务日期截断、页底目录高亮错误和深色顶栏底色错误。部分测试脚本的旧控件名称和异步渲染等待也已更新。构建仍提示主 JavaScript 包较大，后续可单独进行模块加载优化；本轮未调整数据同步、数据库结构或权限规则。
