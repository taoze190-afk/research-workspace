# 整体界面优化 · 2026-10-25

沿用用户确定的淡蓝色风格，统一科研业务页和账号、AI、管理页的视觉层次。本轮修改展示和交互布局，没有调整账号权限、数据结构或科研数据。

后续对 AI 工作室的连续对话、资料面板和手机布局进行了专项优化，见 [AI 工作室界面优化与验证](ai-studio-ui-2026-10-25.md)。以下检查数量对应整体界面优化轮次。

## 登录页精简补充

- 删除顶部“登录 / 注册”切换条，仅保留一个登录提交按钮；注册移至表单底部，注册状态可返回登录。
- 移除英文口号、营销标题、介绍段、功能卡片及账号隔离说明；保留注册密码规则、首账号角色和操作错误等必要提示。
- 使用本地 WebP 淡蓝雾山摄影作为全屏背景，配合独立表单面板；兼容手机及深色模式。图片约 100 KB，页面加载不依赖外部图床。
- 摄影来源与许可记录在 [背景图片说明](../public/images/README.md)。登录页浏览器检查包含三种屏宽、两种主题、唯一登录按钮、背景加载及注册实际提交。

## 已完成

- **应用框架**：侧栏 240px、顶栏 64px，统一正文边距与页面节奏；品牌、研究导航、AI 入口和账号区域分组；底部展示当前账号或本地工作空间。
- **顶栏**：增加可见当前位置、明确的全局搜索文案和主题切换；移除重复悬浮 AI 按钮，消除其对页面主操作的遮挡。
- **工作台**：日期、标题、真实待办提示形成清晰层次；快速捕获与统计卡片分组；手机统计卡片改为两列。
- **业务页头**：项目、任务、实验、文献与设置复用同一页头组件，统一标题、数量、说明和主操作。
- **卡片与列表**：项目卡片突出名称、研究问题、状态、进度与截止日期；全站面板统一边框、圆角和较轻阴影。
- **筛选**：搜索与筛选区使用一致面板；恢复文献库窄屏下的阅读状态、项目和标签筛选。
- **文献库**：未选中条目时显示阅读笔记引导和当前列表的真实阅读状态计数。
- **设置**：增加界面偏好、数据同步、AI、标签、备份和回收站分区锚点，降低长页查找成本。
- **控件与弹层**：统一输入框、下拉框、按钮和对话框的尺寸与间距；调用方显式设置高度时继续保留其控制权。
- **深色模式**：使用更柔和的深蓝灰背景；补充主色按钮、复选框和 AI 对话气泡的专用前景色，改善浅蓝底上的文字对比。
- **图表细节**：热力图月份标签保持一行，避免月份与“月”字分开。

## 查看与复查

截图保存在 `shots/redesign/`；登录与管理页面截图保存在 `shots/platform/`。机器可读报告分别是四份 `*-report.json` 和 `shots/platform/report.json`。

```powershell
npm test
npm run build
node scripts/verify-design.mjs --width=1440
node scripts/verify-design.mjs --width=1280
node scripts/verify-design.mjs --width=768
node scripts/verify-design.mjs --width=390
node scripts/verify-platform.mjs
```

也可以用 `npm run verify:design -- --width=390` 检查指定屏宽。脚本需要本机 Chrome，自动选择空闲端口并在结束后关闭测试浏览器和预览服务。

浏览器验证基于 Chromium；未做真人触屏和 Firefox / Safari 验证。构建仍有原有的主 JavaScript 包体积提示，后续可独立进行路由和数学渲染模块拆包。
