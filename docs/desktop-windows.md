# 研序 Windows 桌面版

## 使用

- `Yanxu-Setup-0.1.0-x64.exe`：安装版，可以选择安装位置，创建桌面和开始菜单快捷方式。
- `Yanxu-Portable-0.1.0-x64.exe`：免安装版，双击运行。首次解包可能需要几秒。
- 支持 Windows 10/11 x64，已内置界面、Node.js 和 SQLite，不需要另装 Node 或启动命令行。
- 首次启动注册的账号是本机管理员，之后可在管理控制台创建用户；各账号科研数据独立。
- AI 需要联网或可连接的本地模型，并配置自己的模型服务。安装包不包含任何密钥和科研数据。

本包未使用商业代码签名证书，Windows 可能显示“未知发布者”。请核对安装包来源及同目录的 SHA256 校验文件。

## 数据位置与备份

安装版和免安装版都将数据保存在 `%APPDATA%\YanxuResearch`，升级程序、移动免安装 EXE 或卸载应用不会主动删除此目录。“免安装”表示无需安装，数据不会随 EXE 自动带走。

按 `Alt` 显示菜单，通过「文件 → 打开数据目录」定位目录。其中：

- `data\research-workspace.db`：账号、权限、研究记录和文件原件。
- `desktop-state.json`：持久化的本机端口。不要删除或修改，否则原浏览器缓存和本机对话的访问地址会改变。
- 其余 Chromium 数据：当前登录状态、本机对话、操作回执和界面设置。
- `desktop.env`：可选的平台模型配置，可能包含密钥，应随备份妥善保管。

**完整备份与换机：先退出研序，再复制整个 `YanxuResearch` 目录；恢复时同样先关闭研序。** 界面中的 JSON 导出适合研究记录迁移，不包含原文件和本机对话。浏览器版、已有服务器版与桌面版的数据相互独立；需要已有研究记录时，在原应用导出，再在桌面版导入。

不要在多个 Windows 账号间共用这个数据目录，不要同时从同步盘打开同一个 SQLite 文件。桌面本机服务只监听 `127.0.0.1`，不提供局域网共享；多人跨设备使用请继续部署服务器版。

## 配置 AI

个人使用可直接到「设置 → AI」配置个人接口，然后在工作室选择「个人接口」。

要使用平台模型，按 `Alt` 打开「文件 → 编辑平台模型配置」，在文件中填写对应环境变量，保存后完全退出并重新启动研序，再到「管理控制台 → 模型」设置服务商、模型名并启用。例如自定义兼容服务：

```dotenv
AI_API_KEY=填写自己的密钥
AI_BASE_URL=https://你的兼容接口/v1
```

DeepSeek、Gemini 等服务商应使用管理控制台所提示的变量名。配置文件保存在本机，不进入分发的安装包。

## 从源码重新打包

```powershell
npm ci
npm run desktop:dist
```

需要 Windows x64、Node.js 24+ 和 Chrome（用来将现有 SVG 品牌图标生成 ICO，可通过 `CHROME_PATH` 指定）。构建会下载 Electron 和 NSIS 工具；最终 EXE 位于 `release`。只运行未打包桌面版可用 `npm run desktop:dev`。

安装包采用明确文件白名单，排除 `server/data`、`.env`、浏览器档案、测试数据及本机密钥。每次发布仍应使用隔离的空白数据目录验证安装和启动。
