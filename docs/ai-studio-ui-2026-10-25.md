# AI 工作室界面优化 · 2026-10-25

延续淡蓝色界面，将 AI 工作室调整为适合连续交流的研究空间。

## 界面与交互

- 对话区占用当前页面可用高度，消息独立滚动，输入区始终可达；短屏压缩页头和空状态。
- 桌面右侧集中展示模型来源、当前模型和选中的研究资料，可收起。平板和手机通过“资料与模型”抽屉操作，输入框旁也可直接添加资料。
- 精简空状态为四个科研任务入口，点击填入问题并聚焦输入框；输入框随内容增高，支持 Ctrl / Command + Enter 发送、Enter 换行。
- 回答采用适合阅读的行宽，提供复制；回看旧内容时停止自动跟随，使用“回到最新”返回底部。
- 已有对话时，切换模型来源、切换或移除资料、新建对话均需确认。取消保留原对话，确认后保留输入草稿。
- 失败、空回复和手动停止均提供重试，重试替换本轮回答，保留此前历史；停止后保留已生成内容。
- 抽屉及确认弹窗关闭后恢复键盘焦点；触发按钮已移除时回退到资料选择框或输入框。
- 浅色、深色模式均复用全站主题变量。

## 验证

- 全量测试 28 个文件、166 个用例通过，其中 AI 工作室定向回归 6 项。
- 类型检查和生产构建通过；原有主 JavaScript 包体积提示仍存在。
- AI 浏览器完整走查 190 项通过，覆盖 1440、1280、768、390px，以及 390×500 短屏，均检查浅色和深色模式。完整报告位于 `shots/ai-studio/report.json`；确认移除资料后的焦点补验 21 项通过，见 `focus-remove-report.json`。
- 检查首屏输入区、长回答、页面横向溢出与外层纵向滚动、流式生成时回看、资料抽屉、确认取消、重试和停止。
- 平台账号和模型调用链路浏览器检查 26 项通过；整体手机界面走查 23 项通过。
- 使用独立临时浏览器、演示资料、临时账号/数据库及本机测试模型，不读取日常浏览器或调用真实模型。
