# 界面与交互稳定性检查 · 2026-10-25

本轮按真实操作检查界面抖动、焦点、滚动位置、编辑保存、账号切换和离线恢复。浏览器测量保留正常动画和占宽滚动条，不依赖静态截图或默认排除用户操作的 CLS 分数。

## 已复现并修复

| 触发操作 | 原因与表现 | 修复 |
| --- | --- | --- |
| 打开新建项目等弹窗 | Tailwind v4 的 `translate` 与入场动画中的 `transform: translate()` 重复居中；1440px 下横向偏移约 280px，动画结束突然归位 | 入场动画仅改变缩放与透明度，居中只由布局负责 |
| 任务搜索为空、切换列表/看板/日历 | 主滚动条出现或消失导致正文宽度变化 15px | 主内容与弹层滚动容器预留滚动条空间 |
| 窄屏任务、实验或设置页 | 主容器未建立定位包含块，部分隐藏的绝对定位元素越过裁剪区域，撑出文档滚动条；页面宽度再变化 14px | 主容器增加相对定位，文档不承担应用内容滚动 |
| 打开 AI 副驾驶 | 普通行内侧栏占用 380px，桌面正文重排，390px 手机正文几乎消失 | 改为独立、可关闭、可恢复焦点的抽屉，底层页面宽度不变 |
| 等待同步、同步完成 | 顶栏状态文字宽度不同，反复推动搜索入口 | 预留统一状态宽度，数字使用等宽形式 |
| 双击文献笔记或实验正文选词 | 双击事件误切换沉浸模式，顶栏和侧栏突然隐藏 | 使用明确菜单入口，选词不再改变布局 |
| 关联选择、保存状态变化 | 关联选择器选中前后高度不同；保存提示长度改变工具栏布局 | 统一控件高度，保存状态预留空间 |
| 从长页面切换导航或关闭弹层 | 新页继承旧滚动位置；无 Radix Trigger、含 React `autoFocus` 的表单不能正确恢复焦点 | 新路径在绘制前滚动至顶部；同路径筛选保留位置；Portal 挂载时捕获打开入口，关闭后恢复焦点 |
| 从账号菜单进入其他页面 | `window.location.assign` 导致整页重载 | 使用应用内导航 |
| 任务连续修改标题和描述后立即关闭 | 单字段防抖互相取消，关闭清理取消最后一笔保存 | 合并完整草稿并串行保存，关闭前提交；失败保留抽屉与重试入口 |
| 切换文献/实验记录、保存中继续输入 | 旧编辑器状态短暂渲染到新记录；并发保存可能覆盖新草稿或过早显示已保存 | 按记录身份隔离编辑器，串行提交最新快照；导出与复制包含当前草稿 |
| 刚编辑完立即退出账号 | 旧编辑器卸载提交可能发生在清镜像后；最后草稿尚未提交 | 退出前统一等待已启用自动保存的编辑器，失败保留当前页面；成功后先屏蔽旧身份再退出及清理 |
| 离线创建任务 | 本地已写入且进入待传队列，返回值却表示失败，表单不关闭，容易重复提交 | 本地保存成功即完成表单操作，未上传状态由队列标注和通知表达 |
| 登录、换号、自动恢复连接 | 业务页先显示空快照或旧快照，随后再读取数据 | 身份和镜像准备完成后展示；按账号隔离首帧数据，忽略过期读取及写入回调 |

## 操作覆盖

- 工作台、项目列表及详情、任务列表/看板/日历、实验列表/参数表/编辑和预览、文献列表及笔记、设置、账号与 AI 工作室。
- 新建项目、任务、文献；关联实验；快速编辑后立即关闭或切换；任务完成、菜单、删除与撤销；文献删除取消。
- 搜索空结果与清空、全局搜索开关、手机导航、侧栏折叠/恢复、主题切换、新页面滚动归零、同页筛选及抽屉关闭保持滚动位置。
- 登录/注册、账号隔离、管理员权限及模型配置；临时服务器断开后的本地录入、队列恢复和真实 SQLite 单条补传；退出前最后一次编辑的落库核对。
- AI 工作室资料抽屉、选定资料发送、流式长回答、上滚阅读、返回最新、失败重试、停止、取消切换资料及焦点回退。

交互录帧覆盖 1440、1280、768、390px；AI 专项另含 390×500 短屏及浅/深色。新建弹窗在修复后横向中心偏差为 0px，AI 开关的底层框架位移为 0px。基线失败报告保留于 `shots/interactions/*-baseline-report.json`，修复后报告为同目录的 `*-report.json`。

服务端检查使用临时账号、临时 SQLite 与临时 Chrome 配置，AI 使用本机测试模型；不读取日常浏览器或正式科研数据。`--fast-timers` 仅缩短测试浏览器原有自动重试间隔，生产逻辑不变。

浏览器自动化基于本机 Chromium。保留正常入场动画、用户主动展开或切换视图时的合理布局变化；没有声称覆盖所有真实手机输入法、系统缩放、Safari 或 Firefox。实验自动保存关闭时仍需手动保存。构建保留原有主 JavaScript 包体积提示。
