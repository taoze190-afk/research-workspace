# 工作区背景、可读性与头像 · 2026-10-25

本轮在淡蓝主题上加入独立的清新风景背景，精简模块说明、调整字号和布局，并实现账号头像。背景采用 [Alex Kolundzija 的蓝天海岸摄影](https://unsplash.com/photos/a-blue-ocean-with-clouds-in-the-sky-IdXHG0j9eiM)，与登录页雾山图片不同。来源和许可见 [图片说明](../public/images/README.md)。

## 背景与阅读

- `public/images/workspace-coast.webp` 为本地静态文件，约 259 KiB，不请求外部图床。
- 背景绝对定位、不接收指针事件、不占内容空间，不使用视差或滚动动画。
- 浅色与深色分别加遮罩；表格、编辑区、表单和 AI 对话面板使用实色承托。实验标题输入也补齐了实色背景。
- 设置 → 界面偏好 → **背景图片** 可开关，刷新后保留选择，切换不改变正文宽度。
- 常用辅助文字调整为 13–14px，正文/阅读/编辑区依场景使用 14–16px，手机文本输入为 16px。热力图坐标和键盘快捷键等非主要信息保留较小字号。

## 本轮额外修复的交互

- 手机页头不再强制拆成两排；文献多操作按钮限制为容器宽度，避免横向溢出。
- 触屏扩展点击区不再覆盖按钮明确的绝对定位。可选日期的清除按钮与输入同排，点击区不会遮住原生日历图标；清除后焦点留在日期输入框。
- 二级菜单通过 Portal 独立渲染，避免被父菜单的裁剪和滤镜限制，修复鼠标无法点击批量优先级的问题。

## 头像

入口：个人账号 → 资料与安全 → 头像。

支持上传、更换、中心裁切压缩、预览、保存、取消和移除。选择本地图片后先预览，按“保存头像”后才更新账号；刷新、重新登录和修改昵称不会丢失头像。头像解码失败时显示昵称首字或默认图标。

客户端接受 JPG、PNG、WebP，原图不超过 5 MB，处理为 256×256 的小图。服务端只接受有限大小的栅格 data URL，校验类型、签名、尺寸与 64 KiB 上限。`PATCH /api/auth/avatar` 使用会话本人身份和既有 CSRF 校验，不接受请求指定其他账号。

服务端迁移 6 仅为 `users` 增加可空头像字段，不修改科研业务表。头像是账号资料；无账号本地模式使用默认图标，离线时保留已有显示并禁用修改。
